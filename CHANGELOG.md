# Changelog

Все изменения в каталоге MCP-серверов для 1С.

## [2026-08-25] (3)

### Добавлено

- `one-s-mcp` — коммерческая платформа MCP-серверов для 1С: локальный семантический поиск по коду и метаданным, граф вызовов, анализ влияния изменений с учётом расширений, справка платформы и БСП, проверка кода по стандартам разработки. Индексация и поиск выполняются на машине разработчика. Добавлена запись в раздел «Коммерческие продукты», строка в сводную таблицу и в матрицу совместимости по транспорту (stdio)

## [2026-08-25] (2)

### Добавлено

- `ИИкона (1c-ai-connector)` — расширение-платформа для интеграции LLM в 1С:Предприятие: агентская петля (function calling), RAG, MCP-сервер, мониторинг ошибок с ИИ-диагнозом, генератор диаграмм. Добавлено по issue [Untru/1c-mcp#4](https://github.com/Untru/1c-mcp/issues/4)

## [2026-08-25]

### Добавлено

- Новый раздел **1C:Element** — неофициальные MCP-инструменты для новой облачной платформы 1С (1cmycloud.com): `elemctl` (CLI + MCP-сервер для Console API v2) и `xbsl` (линтер, LSP и MCP-сервер для XBSL-кода)
- `claude-code-skills-1c` и `cursor-1c-skills` (Desko77) — 116-117 skills и 40 правил для сборки/разбора исходников 1С из XML через Claude Code и Cursor
- `1c-ai-mcp` (Desko77) — MCP-сервер для 1С:Напарник с 12 инструментами и режимом Direct
- Краткая справка о новостях экосистемы MCP и Agent Skills в шапке README (спецификация MCP `2026-07-28`, Agent Skills как открытый стандарт agentskills.io)

### Изменено

- `cursor_rules_1c` переименован в `ai_rules_1c`: проект вырос из Cursor-only набора правил в кросс-платформенный тулкит для 11+ AI-инструментов (13 субагентов, 8+ SKILL-пакетов, ~25 файлов правил)
- Обновлено описание `1c-mcp-metacode`: релизы v2.0.0 и v2.0.1 — встроенный AI-агент, семантический поиск по BSL, поддержка расширений, загрузка из XML-выгрузки, веб-консоль
- Добавлены строки в матрицу совместимости по транспорту (`elemctl`, `1c-ai-mcp`) и в сводную таблицу проектов
