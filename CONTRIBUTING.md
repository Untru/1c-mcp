# Как добавить проект в каталог

Спасибо за интерес! Ниже — правила и шаблон записи.

## Требования

- Проект связан с 1С:Предприятие (или 1C:Element) и реализует/использует MCP, либо это набор skills/правил для AI-агентов
- Open source: публичный репозиторий с README и лицензией
- Коммерческий продукт: рабочий сайт с описанием и ценой

## Шаблон записи

Добавьте запись в подходящий раздел `README.md` (заголовки `###` внутри «Каталог»):

```markdown
#### [Название](https://github.com/owner/repo)

**Одна фраза: что это.** Она же попадёт в колонку «Что это» в топе по звёздам.
2–4 предложения человеческим языком: какую задачу решает, зачем это разработчику 1С, чем отличается от соседей по разделу.

Стек · транспорт · требования · статус ![stars](https://img.shields.io/github/stars/owner/repo?style=flat&label=%E2%AD%90)
```

Статусы: ✅ стабилен и развивается · 🚧 бета · 🔬 эксперимент · 📦 не поддерживается.

Коммерческие продукты — строкой в таблицу раздела «Коммерческие продукты» с ценой.

## Топ по звёздам

Руками не редактируется: таблицу между маркерами `<!-- TOP:START -->` и `<!-- TOP:END -->` пересобирает [scripts/update_top.py](scripts/update_top.py) по расписанию (раз в неделю, [workflow](.github/workflows/update-top.yml)). В топ попадает любая запись вида `#### [Имя](https://github.com/owner/repo)`. Локально:

```bash
GITHUB_TOKEN=$(gh auth token) python scripts/update_top.py
```

## Процесс

1. **Issue** — если хотите предложить проект, не оформляя PR
2. **Pull Request** — добавьте запись по шаблону и строку в `CHANGELOG.md`

## Правила

- Один PR = один проект (или группа от одного автора)
- Описание на русском, без маркетинга — что делает и зачем
- Без рабочего кода или документации не добавляем
